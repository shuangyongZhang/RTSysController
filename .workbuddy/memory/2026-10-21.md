# 2026-10-21 代码审查

对 MotorControlApp（.NET 10 WinForms 电机控制，ZMotion SDK + 5 种波形）做了全文 bug 审查，未改代码，仅输出清单。主要发现：

1. **LimitTriggered / Disconnected 事件无人订阅**（MainForm.cs:656/662 是死代码，连接时只挂了 SensorDataReceived）→ 软限位强停提示、归零/点动硬限位脱困诊断全部丢失。
2. **在线改轴号只拦了 ApplyMotionParams**（ZMotionDeviceController.cs:362），前进/后退/归零/找零/应用限位/状态轮询仍用实时轴号，UI 连接后也不禁用轴号框。
3. 方波/脉冲真机运行无看门狗（WaveformLoopAsync 只靠 IsFinished，轴卡死会永远跑）。
4. ApplyRunSpeed 回读校验的 mm 换算漏乘 Units（ZMotionDeviceController.cs:394）。
5. TryParseInt/Float 用当前区域文化，与全项目 InvariantCulture 不一致。
6. 模拟器模式"应用限位"静默无响应、"归零"误报"未连接"。
7. 其余低危：TipForm 高度截断长消息；ConnectAsync 轮询 Bus_InitStatus 不判 rc 傻等 20s；自校准回报读当前 config 而非运行捕获值；Device_Disconnected 死代码。

用户偏好：中文交流；项目为实机联调阶段，重视错误提示可读性与失败可定位性（代码里大量诊断文案）。
